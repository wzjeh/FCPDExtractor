🔬 影响因素提取功能使用说明
═══════════════════════════════════════════════════════

📋 功能概述
────────────────────────────────────────────────────────

在步骤5总结阶段,新增了**影响因素提取功能**,自动分析文献中各参数对研究结果的影响关系,
并输出为易读的Markdown表格格式。

**特点**:
✅ 混合方式: 关键词快速筛选 + LLM深度理解
✅ 数据源优化: 使用已过滤和抽象后的文本
✅ 输出可读: Markdown表格格式
✅ 智能提取: 自动识别小节标题和Results部分的因果关系


🎯 工作流程
────────────────────────────────────────────────────────

Phase 1: 关键词筛选
┌─────────────────────────────────────────────┐
│ • 匹配小节标题:                              │
│   "2.1.3. Effect of Sulfuric Acid Strength" │
│ • 匹配因果描述:                              │
│   "increased conversion"                    │
│   "yield decreased"                         │
│ • 重点关注Results部分                       │
└─────────────────────────────────────────────┘
                    ↓
Phase 2: LLM深度提取
┌─────────────────────────────────────────────┐
│ 对每个候选段落:                              │
│ • LLM分析提取: 因素|指标|关系               │
│ • 参数: max_tokens=200, temp=0.1            │
│ • 格式: Factor | Metric | Relationship      │
└─────────────────────────────────────────────┘
                    ↓
Phase 3: 格式化输出
┌─────────────────────────────────────────────┐
│ 生成Markdown表格:                            │
│ | 影响因素 | 影响的指标 | 影响关系 |         │
│ |---------|-----------|---------|          │
│ | ...     | ...       | ...     |          │
└─────────────────────────────────────────────┘


📂 输出文件
────────────────────────────────────────────────────────

**文件名格式**:
Embedding_[PDF名称]_Impact_Analysis.txt

**示例**:
Embedding_101021acsoprd7b00291_Impact_Analysis.txt

**文件内容**:
# 影响因素分析

|---------|-----------|---------|
| 硫酸强度 (Sulfuric Acid Strength) | TFMB转化率 | 硫酸强度增加导致TFMB转化率提高 |

| 流速 (Flow Rate) | 混合效率 | 低流速改善反应物混合,提高转化率 |

💡 实现细节
────────────────────────────────────────────────────────

**代码位置**: `Text Extraction/Unified_Text_Processor.py`

**核心方法**:
1. `extract_influence_factors_with_llm(df)` - 主提取函数
2. `_parse_influence_output(llm_output)` - 解析LLM输出
3. `_format_as_markdown_table(results)` - 格式化为Markdown

**调用时机**:
在 `process_text_file_comprehensive()` 方法中,
位于 `summarize_document_overall()` 之后,文件清理之前。

**数据流**:
df_abstract (优先) → df_filtered → df (原始)
                        ↓
        extract_influence_factors_with_llm()
                        ↓
              Markdown表格文本
                        ↓
         _Impact_Analysis.txt 文件


⚙️ 参数配置
────────────────────────────────────────────────────────

**LLM生成参数**:
- max_tokens: 200 (足够输出多条关系)
- temperature: 0.1 (确保输出稳定)
- top_p: 默认

**处理限制**:
- 最多处理15个候选段落 (平衡速度和全面性)
- 段落长度限制800字符 (避免超出context)
- 输出字段长度限制 (保持表格整齐)


⚠️ 注意事项
────────────────────────────────────────────────────────

1. **依赖抽象文本**
   - 优先使用 `_Abstract.txt` 作为输入
   - 确保步骤4和步骤5都已执行

2. **LLM模型**
   - 使用与总结相同的模型 (在Cell 7配置)
   - 建议使用 Meta-Llama-3.1-8B 或更大模型

3. **处理时间**
   - 每个段落需要LLM推理,较慢
   - 10个段落约需1-2分钟

4. **输出质量**
   - 取决于原文中是否明确讨论影响关系
   - 如果文献未专门讨论,可能提取结果较少

5. **重新运行**
   - 如果需要重新生成,删除 `_Impact_Analysis.txt` 后重新运行步骤5

🔧 故障排查
────────────────────────────────────────────────────────

**问题1**: 未检测到影响因素
┌─────────────────────────────────────────────┐
│ 原因: 原文中没有明确的 "Effect of" 等标题   │
│ 解决: 正常现象,说明文献未专门讨论影响关系  │
└─────────────────────────────────────────────┘

**问题2**: 提取结果过少
┌─────────────────────────────────────────────┐
│ 原因: 关键词模式过于严格                     │
│ 解决: 可以修改 effect_patterns 正则表达式   │
└─────────────────────────────────────────────┘

**问题3**: LLM输出格式错误
┌─────────────────────────────────────────────┐
│ 原因: 模型不遵循 "Factor|Metric|Relationship"│
│ 解决: _parse_influence_output 有回退机制    │
└─────────────────────────────────────────────┘

**问题4**: 运行时间过长
┌─────────────────────────────────────────────┐
│ 原因: 候选段落过多                           │
│ 解决: 已限制最多处理15个段落                │
└─────────────────────────────────────────────┘
