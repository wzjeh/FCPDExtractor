# 双模式使用说明

## 📋 当前架构

### 三个引擎，两种模式

| 引擎 | 标准5步模式 | 快速直达模式 |
|------|------------|-------------|
| **本地LLM** | ✅ 默认强制 | ❌ 不支持 |
| **Qwen** | ✅ 可选 | ✅ 可选 |
| **Gemini** | ✅ 可选 | ✅ 可选（但会被安全过滤） |

### 标准5步模式（所有引擎通用）

**流程**：
```
步骤1: PDF → TXT（32K字符）
步骤2: 预处理（直通）
步骤3: 嵌入相似度筛选 → 20段
步骤4: LLM内容过滤 → ~20段
步骤5: 
  - 抽象（压缩为摘要）
  - 逐段总结（每段生成JSON）
  - 整篇汇总（合并为1个最优JSON）
  - 影响因素（提取因果关系）
```

**输出文件**（5个）：
- `_Filtered.txt`
- `_Abstract.txt`
- `_Summarized.txt`
- `_Overall.txt`
- `_Impact_Analysis.txt`

**API调用数**（在线LLM）：~30次
**时间**：1-2分钟

---

### 快速直达模式（仅在线LLM）

**流程**：
```
步骤1: PDF → TXT（32K字符）
步骤2: 直接喂给LLM（跳过嵌入、过滤、抽象）
步骤3: 
  - 一次性提取Overall JSON（从全文80K字符）
  - 一次性提取Impact（从全文40K字符）
```

**输出文件**（2个）：
- `_Overall.txt`
- `_Impact_Analysis.txt`

**API调用数**：2次
**时间**：~30秒

---

## 🚀 如何使用

### 在Notebook中切换模式

#### 方法1：修改步骤5单元格开头

**启用快速模式**（在线LLM）：
```python
USE_FAST_MODE = True  # Qwen/Gemini快速直达
```

**使用标准5步**（所有引擎）：
```python
USE_FAST_MODE = False  # 强制标准5步流程
```

#### 方法2：替换整个步骤5单元格

复制 `NOTEBOOK_STEP5_DUAL_MODE.py` 的内容，替换步骤5单元格。

代码会自动判断：
- `ENGINE='local'` → 强制标准5步
- `ENGINE='qwen'` 且 `USE_FAST_MODE=True` → 快速模式
- `ENGINE='gemini'` 且 `USE_FAST_MODE=True` → 快速模式（但可能被过滤）

---

### 在命令行中使用

**标准5步**（默认）：
```bash
python main.py --engine qwen --mode comprehensive
```

**快速模式**（需修改main.py支持）：
```bash
python main.py --engine qwen --mode fast
```

## 📊 模式对比

### 标准5步 vs 快速直达

| 对比项 | 标准5步 | 快速直达 |
|--------|---------|----------|
| **输入** | 20段过滤后文本 | 完整PDF全文 |
| **处理步骤** | 嵌入→过滤→抽象→总结 | 直接提取 |
| **API调用** | ~30次 | 2次 |
| **时间** | 1-2分钟 | 30秒 |
| **信息丰富度** | 中（经过筛选压缩） | 高（全文上下文） |
| **准确性** | 高（多次验证） | 中（依赖单次理解） |
| **输出文件** | 5个 | 2个 |
| **本地LLM支持** | ✅ | ❌ |
| **Qwen支持** | ✅ | ✅ |
| **Gemini支持** | ✅ | ⚠️ 会被安全过滤 |

## 💡 使用建议

### 标准5步模式适用场景：
- ✅ 本地LLM（必须使用）
- ✅ 需要中间文件调试
- ✅ 需要高准确性（多次验证）
- ✅ 论文很长（>100页）

### 快速直达模式适用场景：
- ✅ 使用Qwen-Plus
- ✅ 批量处理大量论文
- ✅ 只需要Overall+Impact结果
- ✅ 论文较短（<20页）
- ❌ 不推荐Gemini（安全过滤问题）

---

## 🔧 当前默认配置

- **本地LLM**: 强制标准5步
- **Qwen**: 快速模式（`USE_FAST_MODE=True`）
- **Gemini**: 快速模式（但会被拦截，建议改为标准5步）
