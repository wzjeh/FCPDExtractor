## Summary

The influence factor extraction module has been completely rewritten with:

## Key Improvements

### 1. Intelligent Candidate Scoring

**Old Method:**
- Simple regex pattern matching
- No prioritization
- Processed up to 15 paragraphs sequentially

**New Method:**
- Multi-factor scoring system:
  * Title patterns ("Effect of X"): +50 points
  * Results/Discussion sections: +20 points
  * Factor keywords (temperature, flow rate, etc.): +5 each
  * Metric keywords (conversion, yield, etc.): +5 each
  * Causal verbs (increase, decrease, etc.): +3 each
- Minimum score threshold: 10 points
- Top K candidates selected (default: 12, configurable)

**Result:** More relevant paragraphs selected, better precision


### 2. Batch LLM Processing

**Old Method:**
- 1 LLM call per paragraph
- 15 paragraphs = 15 API calls
- Simple text output parsing

**New Method:**
- Process 5 paragraphs per batch (configurable)
- 12 paragraphs = 3 API calls (60% reduction!)
- Structured JSON array output
- Robust JSON parsing with sanitization

**Result:** Faster execution, lower costs, more structured data


### 3. Enhanced Data Structure

**Old Output:**
```
Factor | Metric | Relationship
Temperature | Selectivity | Lower temp increases selectivity
```

**New Output:**
```json
{
  "factor": "Temperature",
  "metric": "Selectivity",
  "direction": "increase",
  "magnitude": 90.97,
  "unit": "%",
  "condition": "273 K",
  "evidence": "lower temperature increases p-NB selectivity to 90.97%"
}
```

**Result:** Richer, more actionable information


### 4. Terminology Normalization

**Mapping Rules:**
- Temperature/temp → Temperature
- Flow rate/flow → Flow Rate
- Residence time → Residence Time
- Sulfuric acid → Sulfuric Acid Strength
- Conversion/yield/selectivity → Standardized names

**Noise Filtering:**
- Removes "Multiple factors / Performance metrics" placeholders
- Filters out entries with missing or vague data
- Deduplicates by factor-metric pairs

**Result:** Clean, consistent output


### 5. Enhanced Markdown Table

**Old Format:**
| Factor | Metric | Relationship |

**New Format:**
| Factor | Metric | Direction | Magnitude/Unit | Condition | Evidence |
|--------|--------|-----------|----------------|-----------|----------|
| Temperature | Selectivity | ↑ | 90.97 % | 273 K | lower temperature increases... |
| Flow Rate | Mixing | ↑ | - | 0.8-2.2 mL/min | low flow improves mixing |

**Columns:**
1. **Factor**: Normalized influence factor name
2. **Metric**: Affected performance metric
3. **Direction**: ↑ (increase) / ↓ (decrease) / - (unclear)
4. **Magnitude/Unit**: Quantitative change with units
5. **Condition**: Specific experimental conditions
6. **Evidence**: Short quote from original text

**Result:** More informative, scannable table
