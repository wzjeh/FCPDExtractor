## Critical Improvement: Adaptive Factor Discovery

**Problem Identified:**
The initial implementation relied too heavily on generic keywords (temperature, flow rate, etc.),
missing paper-specific factors like:
- "Sulfuric acid strength" (not just "acid")
- "Sand particle size" (not just "diameter")
- "Microchannel geometry" (not just "reactor")
- "Nitration mixture composition"
- "Quench water temperature"

**Solution:**
Completely redesigned the extraction logic to be **adaptive** and **pattern-based**
rather than keyword-dependent.


## Key Changes

### 1. Adaptive Candidate Scoring

**Scoring Hierarchy (highest to lowest priority):**

1. **Explicit Section Titles** (+80 points)
   - Pattern: "2.1.3. Effect of [FACTOR]"
   - Captures the exact factor name from section heading
   - Example: "Effect of Sulfuric Acid Strength" → extract "Sulfuric Acid Strength"

2. **Causal Relationship Patterns** (+15 points each)
   - "X affects/influences/controls Y"
   - "Y is affected/influenced/controlled by X"
   - "higher/lower X results in increased/decreased Y"
   - "at [condition], Y reached/was [value]"
   - **Paper-specific factors automatically discovered**

3. **Results/Discussion + Metrics** (+25 points)
   - Paragraphs from Results/Discussion sections
   - Must also mention metrics (conversion, yield, etc.)
   - Captures experimental observations

4. **Causal Verbs + Metrics** (+8 points if co-located, +3 otherwise)
   - Extended verb list: increase, decrease, improve, enhance, reduce, affect, influence,
     impact, promote, inhibit, facilitate, optimize, control, determine, depend, vary, change, modulate
   - Higher score when verb appears within 50 chars of a metric keyword

5. **Quantitative Data** (+10 points)
   - Presence of numbers with units (e.g., "90.97%", "273 K", "1.3 mL/min")
   - Indicates experimental conditions are discussed
   - Helps identify actionable paragraphs

6. **Generic Keywords** (+2-3 points - tie-breaker only)
   - Temperature, flow rate, pressure, etc.
   - Only counted if paragraph already has causal signal
   - Low weight prevents over-reliance on generic terms

**Result:** Discovers paper-specific factors even if they're not in predefined keyword lists!


### 2. Enhanced LLM Prompt

**Old Prompt:**
```
Extract factor, metric, relationship
Examples: Temperature | Selectivity | increases...
```

**New Prompt:**
```
Extract ALL cause-effect relationships from chemical/flow processes.

IMPORTANT: Extract PAPER-SPECIFIC factors (not just generic ones).

Look for:
- Section titles like 'Effect of X'
- Phrases like 'X affects/influences Y'
- Comparisons like 'higher X leads to Y'
- Experimental observations with quantitative data

Output JSON with:
- factor: extract EXACT name from text
  (e.g., "Sulfuric acid strength", "Microchannel diameter", "Sand particle size")
```

**Key Improvements:**
- Explicit instruction to find paper-specific factors
- Examples show specific, not generic, factor names
- Emphasizes extracting exact terminology from the text


### 3. Light Normalization (Preserves Specificity)

**Old Approach:**
- Aggressive mapping: "sulfuric acid" → "Acid Strength"
- Lost paper-specific context

**New Approach:**
- Only fix abbreviations: "temp" → "Temperature", "conc" → "Concentration"
- Preserve full factor names: "Sulfuric acid strength" stays as-is
- Capitalize for consistency but keep original wording
- Result: Paper-specific terminology maintained!

## Technical Implementation

### Scoring System

```python
# Priority 1: Section titles (highest weight)
if re.search(r'(\d+\.\d+\.?\d*\.?)\s*Effect of ([^.\n]{3,60})', text):
    score += 80
    factor_name = match.group(2)  # Exact factor name extracted

# Priority 2: Causal patterns (discover paper-specific factors)
patterns = [
    r'([A-Z][a-z\s]{2,40}) affects ([a-z\s]{3,30})',
    r'([a-z\s]{3,30}) is affected by ([A-Z][a-z\s]{2,40})',
    # ... more patterns
]
for match in find_all_matches(patterns):
    score += 15  # High weight for explicit causality

# Priority 3-6: Context clues
# Results sections, causal verbs, quantitative data, generic keywords
# (see full code for details)
```

### Normalization Strategy

```python
# PRESERVE paper-specific terminology
factor = "Sulfuric acid strength"  # From LLM extraction

# Only fix abbreviations (exact match)
if factor.lower() == "temp":
    factor = "Temperature"
elif factor.lower() == "conc":
    factor = "Concentration"
# ... but keep "Sulfuric acid strength" as-is!

# Just ensure capitalization consistency
if not factor[0].isupper():
    factor = factor[0].upper() + factor[1:]

# Result: "Sulfuric acid strength" (preserved!)
```
