### ✅ 3. CPU Performance Optimization

**Old Version (v1):**
```python
for each paragraph (15x):
    generate LLM prompt           # O(1)
    call LLM API                  # Expensive!
    parse simple text             # O(n)
```
**CPU: Low**, **LLM: High** (15 calls)

**Initial v2 (unoptimized):**
```python
for each paragraph (12x):
    re.search() × 1               # O(n)
    re.finditer() × 4             # O(4n) - SLOW!
    string matching × 30          # O(30n)
    re.findall() × 1              # O(n)
```
**CPU: HIGH** ⚠️, **LLM: Low** (3 calls)

**Optimized v2 (current):**
```python
for each paragraph (12x):
    para_lower = para.lower()     # O(n) - once
    re.search() × 1               # Title pattern only
    if has_causal_verb:           # Pre-filter (fast)
        re.search() × 2 max       # Only 2 key patterns
        break after first match   # Early exit
    string matching × ~15         # Reduced by 50%
    NO re.finditer() in loop      # Removed!
    NO re.findall() in loop       # Moved outside hot path
```
**CPU: Low** ✅, **LLM: Low** (3 calls)


**Performance Improvements:**
1. Pre-filter with fast string checks before expensive regex
2. Reduced patterns from 4 to 2 in hot path
3. Early exit after first pattern match
4. Removed `re.finditer()` and `re.findall()` from inner loop
5. Replaced regex with simple `in` checks where possible

### 🔧 Optimization Techniques Applied

1. **Pre-filtering:**
   ```python
   # Fast check before expensive regex
   has_causal_verb = any(verb in para_lower for verb in ['affect', 'influence', ...])
   if has_causal_verb:  # Only then apply regex
       re.search(pattern, ...)
   ```

2. **Pattern Reduction:**
   ```python
   # Old: 4 patterns
   for pattern in causal_patterns:  # All 4
       re.finditer(pattern, ...)
   
   # New: 2 patterns max
   key_patterns = causal_patterns[:2]  # Only first 2
   for pattern in key_patterns:
       if re.search(...):
           break  # Stop after first match
   ```

3. **String Matching over Regex:**
   ```python
   # Old: re.search(r'\b(result|discussion|...)\b', para)
   # New: any(sec in para_lower for sec in ['result', 'discussion', ...])
   # Faster for simple keyword matching
   ```

4. **Score Capping:**
   ```python
   # Prevent pathological cases
   score += 8 * min(causal_count, 3)  # Cap at 3
   ```
